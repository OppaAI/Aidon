Pre-approvals

A pre-approval lets Aidon run reversible steps for one project without asking every time. Anything that sends, publishes, spends, deletes, or installs always asks. The same list is what WhatsApp and Slack show when you type preapprovals, and you can grant or revoke from there too.

    Keys, hash prefixes only, never real keys

    Each API key is shown by name, scope, and the first characters of its hash. The key itself is never sent to the page.
