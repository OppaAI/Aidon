◈ Aidon Practice
free-time practice windows

While a window is open, Aidon picks your goals at random and runs each one like a usual run, until the first successful pass or the window closes. Every pass gets a practice report here on the Practice page, on Slack, and on WhatsApp; a window that closes with no pass gets a page-only summary. Practice reports never go to a chat conversation, so a practice run cannot be confused with a real run. Live progress shows below; each run works in its own practice folder in the sandbox, so deletes and installs stay there; messages go only to you (your email, WhatsApp, Slack).
