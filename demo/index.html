01 · Natural-language interview

Start with a conversation.

No workflow design or technical prompts required. Aidon asks focused questions, fills in the missing details, and turns the conversation into a clear spec before planning.

How it flows
Your goal→A few questions→Clear spec
Ask modeA short, guided interview shapes the goal around the person asking.

02 · Tools and skills

Build the missing capability.

When a task needs something new, Aidon can draft a reusable tool or skill, test it in a sandbox, and make the proposed change visible for review.

How it flows
Draft tool or skill→Sandbox test→Owner approval
Draft → test → reviewNew capabilities earn their place through tests and owner approval.

03 · Human approval

You stay in control.

Aidon prepares and verifies work in a sandbox. Consequential live actions pause for a human decision, with the proposed action shown before approval.

How it flows
Verify safely→You review→Live action
Verify first. Approve before live actions.The agent's autonomy stays within the boundaries you set.

04 · DAGs and learning

Make the next run smarter.

Each goal becomes a directed acyclic graph: steps, dependencies, and acceptance criteria. Aidon saves successful workflows and adapts them when a similar goal returns.

How it flows
Saved DAG→Adapt steps→Reuse workflow
Plan → complete → reuseSee what depends on what, and build on successful runs.
